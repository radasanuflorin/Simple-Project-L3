## ✨ Despre proiect

Proiect realizat în cadrul **Laboratorului INa**. Pagina mă prezintă pe scurt (student **FIESC**) și trimite vizitatorul către site-ul meu personal, **[radasanuf.com](https://radasanuf.com)**.

## 🎨 Ce conține pagina

| Secțiune | Descriere |
|---|---|
| **Header** | Bară de navigare fixă, cu efect de sticlă (blur) |
| **Hero** | Salut + **butonul mare** către radasanuf.com — elementul principal al paginii |
| **Despre mine** | Card cu informații: facultate și site personal |
| **Footer** | Copyright și link către site |

## 🚀 Funcționalități

- 🔘 **Buton principal uriaș** cu gradient animat, glow pulsant și săgeată care se rotește la hover
- 🌙 **Temă dark** cu gradiente mov–cyan
- 📱 **Responsive** — arată bine pe desktop, tabletă și telefon
- ♿ **Accesibil** — focus vizibil la tastatură și respectă `prefers-reduced-motion`
- ⚡ **Fără JavaScript și fără framework-uri** — doar HTML + CSS

## 🛠️ Cum rulezi proiectul

```bash
git clone https://github.com/radasanuflorin/Simple-Project-L3.git
cd Simple-Project-L3
```

Apoi deschide `index.html` în browser — nu e nevoie de instalări.
